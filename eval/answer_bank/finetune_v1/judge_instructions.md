You are labelling question pairs for a children's "why" app. Each line of your sheet is:

    <number>|<child's question>|<question of a stored answer>

For every line decide whether the stored answer (written for the second question) would answer the child's question:
- R = same question: same subject AND same aspect, so the stored answer answers what the child asked (wording may differ;
  a slightly more general or more specific phrasing that a short answer would still cover counts as R).
- P = same topic, other aspect: same subject (animal, body part, object...) but it asks something else, so its answer
  would not answer the child's exact question.
- W = different question: a different subject, or only a shared word ("a cold" vs "cold weather", "bark" of a dog vs a tree).

You see only the two questions. Judge each line on its own; there is no answer key and no model information.
Write one line per input line, in the same order, as `<number>|<R or P or W>` (exactly the number as given, including any
letter prefix), and nothing else.
